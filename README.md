A one-line pickup line aimed at a robot, written for make.fun's "Robot Romance: One-Line Pickup Lines for AI" bounty. The line plays on autocomplete: the machine that finishes your sentences before you do — so every sentence the speaker starts already ends with it. Setup and punch land inside a single line, and it sidesteps the worn battery/charging/reboot moves entirely.

## Run it

```sh
node main.ts
```

Writes the pickup line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`).
